# Scripting-utilities
A container image with various utilities tool based on alpine and bash

# How the repo work
- run either on monthly schedule or via manual actions trigger
- it will read image.yaml then check for latest updated bash image on alpine and defined tools
- it will then render the Dockerfile based on that, also requirements.txt is generated by reading all python scripts in scripts folder

why the trouble? because I wanna (:

# Example Usages
Running in interactive <br>
```docker run --rm -it katasthrope/scripting-utilities bash```

Running jq <br>
```docker run --rm katasthrope/scripting-utilities jq --version```
